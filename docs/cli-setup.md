# BugzillaRevamp CLI (`bz`) — Team Setup & Quickstart Guide

Welcome to the **BugzillaRevamp CLI** (`bz`) guide! This command-line utility provides rapid, keyboard-first terminal access to bug tracking, interactive triage, dependency graph visualization, CVSS v4.0 scoring, AI thread summaries, and release readiness metrics.

---

## 1. Prerequisites & Environment Setup

Before running the CLI, make sure your environment meets the following requirements:

1. **Node.js**: Version 20.x or higher (`node -v`).
2. **Monorepo Installed**: Run `npm install` from the root workspace directory.
3. **Backend API Running**: The backend server must be running on port 3001 (`http://localhost:3001`).

```bash
# Start backend API (if not already running)
npm run dev:api
```

---

## 2. Installation & Build

From the workspace root directory, compile the shared packages and CLI code:

```bash
# 1. Build shared package & CLI
npm --prefix packages/shared run build
npm --prefix apps/cli run build

# 2. (Optional) Global Command Link
# Allows you to use `bz` directly from any terminal window
cd apps/cli
npm link
cd ../..
```

If you prefer not to install globally, you can invoke the CLI using `npx bz` or `npm run bz --` from the project root.

## 3. Quickstart & Authentication

### 1-Click Persona Logins

The CLI supports instant authentication via preset personas:

| Persona Name | Role | Email | Command |
|---|---|---|---|
| `admin` | System Administrator | `admin@bugzilla.local` | `npx bz auth login --persona admin` |
| `alice` | Senior Developer | `alice@mozilla.com` | `npx bz auth login --persona alice` |
| `bob` | QA Engineer | `bob@mozilla.com` | `npx bz auth login --persona bob` |
| `carol` | Security Lead | `carol@mozilla.com` | `npx bz auth login --persona carol` |

### Log In as Alice

```bash
npx bz auth login --persona alice
```

### Verify Authentication Status

```bash
npx bz auth me
```

## 4. Feature Commands & Hands-On Examples

### 🐛 Bug Management (`bz bug` / `bz ls`)

#### List & Filter Bugs
```bash
# List all open bugs
npx bz bug list

# Filter by status and priority
npx bz bug list --status CONFIRMED --priority P1

# Output as JSON
npx bz bug list --json
```

#### View Detailed Bug Report
```bash
npx bz bug view 101
```

#### Create a New Bug
```bash
npx bz bug create \
  --summary "WebSocket reconnection fails on network drop" \
  --description "1. Connect WS\n2. Disable network\n3. Re-enable network\n4. Connection hangs" \
  --product-id 1 \
  --component-id 1 \
  --priority P2 \
  --severity major
```

#### Update Bug Status (State Machine)
```bash
# Move to IN_PROGRESS
npx bz bug status 101 IN_PROGRESS

# Resolve Bug as FIXED
npx bz bug status 101 RESOLVED --resolution FIXED
```

---

### 💬 Comments & Stdin Piping (`bz comment`)

#### Read Comment Log
```bash
npx bz comment list 101
```

#### Add Comment directly or pipe from stdout/file
```bash
# Direct argument comment
npx bz comment add 101 "Verified fix on Firefox 128.0 build."

# Pipe stdout/file into comment body
cat release_notes.md | npx bz comment add 101
```

---

### 📊 Dependency Graph & CPM Critical Path (`bz dep` / `bz graph`)

#### View Visual ASCII CPM Graph & Bottlenecks
```bash
npx bz graph 101
```

#### Add / Remove Dependencies
```bash
# Bug 101 blocks Bug 102
npx bz dep add 101 102

# Remove dependency edge
npx bz dep remove 101 102
```

---

### 🔒 CVSS v4.0 & Security Management (`bz cvss` / `bz security`)

#### Calculate CVSS v4.0 Score Offline
```bash
npx bz cvss "CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N"
```

#### Update Bug Security & Embargo Settings
```bash
npx bz security update 101 \
  --vector "CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N" \
  --security true \
  --embargo 2026-11-30
```

## 6. Troubleshooting

- **`CliApiError: 401 Unauthorized`**: Your session cookie expired or is missing. Run `npx bz auth login --persona alice`.
- **`fetch failed` / ECONNREFUSED**: Ensure the API server is running on `http://localhost:3001`. You can override the API URL using `npx bz --api-url http://localhost:4000 <command>`.
